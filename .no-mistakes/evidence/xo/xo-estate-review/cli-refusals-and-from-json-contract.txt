Scope refusals and the --from-json contract, driven live
========================================================

$ bin/xo-estate-review.sh torvalds
  xo-estate-review.sh: GitHub reports owner 'torvalds' as type 'User', not an organization; an estate is an organization or one of its repositories as owner/repo
  exit 2

$ bin/xo-estate-review.sh xo-estate-no-such-org-9f3a2
  xo-estate-review.sh: could not read the owner 'xo-estate-no-such-org-9f3a2': error: "gh: Not Found (HTTP 404)" code: NOT_FOUND 
  exit 1

Rendering a stored model, collected live from jqlang/jq:

$ bin/xo-estate-review.sh --from-json live-model.json > a.md
$ bin/xo-estate-review.sh --from-json live-model.json > b.md
$ cmp a.md b.md
  (identical; two reports of the same estate compare line for line)

The one bound the model can satisfy is honoured:

$ bin/xo-estate-review.sh --from-json live-model.json           | grep "further pull requests"
  76 further pull requests are in this report's model but not listed above; raise `--max-listed` to see them, either on a fresh run or on this report's model with `--from-json`.
$ bin/xo-estate-review.sh --from-json live-model.json --max-listed 0 | grep -c "further pull requests"
  0 (every kept row is now listed)
